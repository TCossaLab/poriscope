# Tutorial Data

The data used in the YouTube tutorial series is archived on the Federated Research Data Repository (FRDR):

**DOI:** [10.20383/103.01599](https://doi.org/10.20383/103.01599)


> Note: The full dataset is ~9.92 GB. Individual `.log` and `.json` files can be downloaded separately from the FRDR page if you only need specific channels.

The reference `.db` files generated during the Tutorial are also included directly in this folder.
