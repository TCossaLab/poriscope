Plugin Development
==================

.. note::

   Every plugin contributed to Poriscope — data plugin or frontend plugin family —
   is checked automatically before it can be merged: formatting, static typing,
   docstring consistency, and a dedicated plugin interface compliance test. None of
   this requires prior experience with these tools; see :ref:`quality_control` for a
   plain-language walkthrough, and :ref:`pre_pr_checklist` for the exact steps to run
   before opening a pull request.
