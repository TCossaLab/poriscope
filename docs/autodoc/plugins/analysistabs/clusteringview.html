ClusteringView¶

class ClusteringView(*args, **kwargs)

Bases: MetaView, WalkthroughMixin

Subclass of MetaView for displaying and interacting with clustering analysis.

Handles plotting, user input, and signal exchanges.

ClusteringView.notify_plugin_state_changed(metaclass: str, plugin_key: str, reason: str) → None¶

Called when some other plugin instance’s state changed elsewhere in the app. Refreshes this tab’s column list only when the change concerns a MetaDatabaseLoader’s columns and the loader that changed is the one currently selected here; any other metaclass, reason, or a loader that isn’t currently selected in this tab is ignored.

Parameters:

  • metaclass (str) – The metaclass of the plugin instance whose state changed.

  • plugin_key (str) – The unique key identifying the plugin instance that changed.

  • reason (str) – A short string identifying what kind of change occurred.

Returns:

None

Return type:

None

ClusteringView._load_metadata_and_cluster(config: Dict[str, Any], loader: str) → Tuple[Any, Any, Any, List[Any], List[Any], List[Any], List[Any]]¶

Loads metadata from the database and performs clustering.

Parameters:

  • config (Dict[str, Any]) – Dictionary with selected columns and method configuration.

  • loader (str) – Identifier of the loader plugin.

Returns:

Tuple containing clustered data, labels, confidence, logs, normalized flags, units, and plot flags.

Return type:

Tuple[Any, Any, Any, List[Any], List[Any], List[Any], List[Any]]

Raises:

  • KeyError – If a duplicate column is selected, or if a selected column is missing from the loaded dataframe.

  • ValueError – If the metadata query cannot be generated, no data matches the query, or the clustering method/parameters are invalid or missing.

ClusteringView._merge_clusters(keep: Any, merge: Any) → None¶

Merges two clusters by reassigning the label.

Parameters:

  • keep (Any) – Cluster label to keep. Arrives as combo box text (or None when unset) and is reassigned in place by int() below, hence the loose annotation.

  • merge (Any) – Cluster label to merge into the keep label. Arrives as combo box text (or None when unset) and is reassigned in place by int() below, hence the loose annotation.
