MetadataView¶

class MetadataView()

Bases: MetaSubsetTabView

Subclass of MetaSubsetTabView for visualizing and interacting with metadata plots.

This view supports a wide variety of statistical visualizations, including: 1D histograms, KDEs, capture rates, scatterplots, heatmaps, and event overlays. Also provides walkthroughs and export options.

Attributes:

metadata_plots (List[str]): List of supported metadata-based plot types. event_data_plots (List[str]): List of supported event-based plot types. subset_export_count (int): Counter for naming exported subsets. plot_initialized (bool): Indicates whether a plot is currently initialized. no_cached_data (bool): True if data is not cached due to size.

MetadataView.on_subset_export_started() → None¶

Move to the next export index, now that this one is running.

The index names the export in the dialog and keys its worker, so it advances only for an export that was actually staged - which is what the Controller calling this says. The Controller counts the subset before staging anything, so an export refused for being empty never reaches here and the next dialog offers the same name again. Kept here rather than counted in the Controller because the dialog needs it before the request goes out, and one owner cannot drift from itself.

Returns:

None

Return type:

None

MetadataView.set_capture_rate(bin_edges: ndarray[tuple[int, ...], dtype[float64]], bincenters: ndarray[tuple[int, ...], dtype[float64]], val: ndarray[tuple[int, ...], dtype[float64]], fit: ndarray[tuple[int, ...], dtype[float64]], rate: float, error: float, data: ndarray[tuple[int, ...], dtype[float64]], ax: Axes, x_label: str, y_label: str, dataset_label: str) → None¶

Draw the inter-event time histogram and the exponential fitted to it.

The answering half of capture_rate_requested. The binning and the fit are made together below, so both describe the same intervals.

The histogram is drawn on the edges the fit was made against, rather than on this widget’s own binning of the same request. Handing matplotlib a bin count instead would let it bin independently, and the counts the fit used and the bars the user sees could then differ with nothing to say so.

Parameters:

  • bin_edges (npt.NDArray[np.float64]) – the edges the counts and the fit were computed on

  • bincenters (npt.NDArray[np.float64]) – the center of each bin

  • val (npt.NDArray[np.float64]) – the counts in each bin

  • fit (npt.NDArray[np.float64]) – the fitted curve evaluated at the bin centers

  • rate (float) – the fitted capture rate in Hz

  • error (float) – the 95% confidence half-width on the rate

  • data (npt.NDArray[np.float64]) – the log inter-event times the histogram is built from

  • ax (Axes) – the axis object on which to plot

  • x_label (str) – the x axis label, already formatted

  • y_label (str) – the y axis label

  • dataset_label (str) – string to label the dataset

Returns:

None

Return type:

None

MetadataView.set_column_units(units: List[str | None]) → None¶

Receive one units string per plotted column, in the columns’ own order.

One list in one call, rather than one string per round trip accumulated here. Accumulating them meant a lookup that failed appended the previous column’s units instead of nothing, and the axis was labelled with the wrong unit; handed over together, the count either matches the columns or the answer is missing entirely.

Parameters:

units (List[Optional[str]]) – one units string per column, None where the loader has none

MetadataView.set_event_overlay(traces: Sequence[Tuple[ndarray[tuple[int, ...], dtype[float64]], ndarray[tuple[int, ...], dtype[float64]]]]) → None¶

Overlay one subset’s event traces on a shared normalised time axis.

The answering half of event_overlay_requested. The baseline subtraction and the per-event time base are made by MetadataModel.build_event_overlay() - both are exported with the plot; what is left here is the drawing, including the alpha each trace is given - a shorter event is drawn more opaquely than a longer one so the short ones are not lost under the crowd, and that number is read by nothing outside these axes.

Parameters:

traces (Sequence[Tuple[npt.NDArray[np.float64], npt.NDArray[np.float64]]]) – one (normalised time, rectified current) pair per event

Returns:

None

Return type:

None

MetadataView.set_histogram_bins(values: ndarray[tuple[int, ...], dtype[float64]], dataset_label: str, bincenters: ndarray[tuple[int, ...], dtype[float64]], widths: ndarray[tuple[int, ...], dtype[float64]], counts: Sequence[ndarray[tuple[int, ...], dtype[float64]]], hist_min: float, hist_max: float, ax: Axes, x_label: str, logx: bool, norm: bool) → None¶

Draw every overlaid dataset onto one shared set of bin edges.

The answering half of histogram_bins_requested. This is handed each dataset’s tallies rather than the edges to tally against, and the edges themselves do not come back: nothing here draws with them once the counting is done elsewhere, and returning them would invite a second tally against them.

Parameters:

  • values (npt.NDArray[np.float64]) – the newest dataset’s raw column values, to accumulate

  • dataset_label (str) – the newest dataset’s label

  • bincenters (npt.NDArray[np.float64]) – the center of each bin, which the bars are drawn at

  • widths (npt.NDArray[np.float64]) – the width of each bin

  • counts (Sequence[npt.NDArray[np.float64]]) – one array of per-bin counts per overlaid dataset, index-aligned with the accumulated labels

  • hist_min (float) – the shared lower limit, widened by this dataset

  • hist_max (float) – the shared upper limit, widened by this dataset

  • ax (Axes) – the axis object on which to plot

  • x_label (str) – the x axis label, already formatted but not yet log-marked

  • logx (bool) – was the data log-scaled, and so should the label say so

  • norm (bool) – normalise each dataset to a fraction rather than a count

None

MetadataView.set_kernel_densities(values: ndarray[tuple[int, ...], dtype[float64]], dataset_label: str, densities: Sequence[Tuple[ndarray[tuple[int, ...], dtype[float64]], ndarray[tuple[int, ...], dtype[float64]]]], hist_min: float, hist_max: float, ax: Axes, x_label: str) → None¶

Draw one filled density curve per overlaid dataset.

The answering half of density_requested. The curve arrives already evaluated, so it is computed once rather than the three times drawing it would otherwise need. The newest dataset joins the overlay here as its raw column, because the Model re-filters every accumulated dataset on each update and a pre-filtered one would be filtered twice.

  • hist_min (float) – the shared lower limit, widened by this dataset

  • hist_max (float) – the shared upper limit, widened by this dataset

  • ax (Axes) – the axis object on which to plot

  • x_label (str) – the x axis label, already formatted

MetadataView.update_units(loader: str, column: str, axis: str) → None¶

Ask the Controller for a column’s units, for this tab’s axis unit labels.

On this tab rather than on MetaSubsetTabView, although both subset tabs inherit that base: the protein tab has no units label, keeps no units cache and labels its axes with hardcoded literals, so it has nothing to do with the answer. Putting it back on the base would give that tab an inherited request nothing answers.

Parameters:

  • loader (str) – Name of the database loader.

  • column (str) – Name of the column to get units for.

  • axis (str) – Axis being updated (‘x_axis’, ‘y_axis’, etc.).

Returns:

None
