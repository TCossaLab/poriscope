# Lesson index

Every lesson in this skill, by ID. Grep this file for a symptom or keyword, then open the linked file and
read the lesson in full - the case matters as much as the rule. The S series is this skill's; the method
skills use C, D, E, I, N, P, V and X.

## Recognising (S) - [recognizing.md](recognizing.md)

- **S1** Sort every lesson by audience before deciding where it goes
- **S2** Extend an existing skill before creating one
- **S3** A new skill is a standing cost to every session
- **S4** Distil from finished work; first-of-a-kind work is where the lessons are
- **S5** Split a skill when most of its lessons apply outside its trigger
- **S6** A rule that must hold every time is not a skill
- **S7** Log corrections as they happen, both kinds

## Anatomy (S) - [anatomy.md](anatomy.md)

- **S8** The description names every stage, or that stage never triggers
- **S9** Every rule carries its case
- **S10** Put what matters most at the top of SKILL.md
- **S11** Generalise the rule, keep the case
- **S12** Write standing rules, not one-time steps

## Maintaining (S) - [maintaining.md](maintaining.md)

- **S13** A skill is installed only once you have seen it load
- **S14** One editable source per skill; copies drift
- **S15** Restructuring a skill strands its tooling
- **S16** Move lessons verbatim, keep their IDs, and check by script
- **S17** Judge a long-horizon skill by the next real piece of work
- **S18** Keep a skill uploadable if it will ever leave the machine
